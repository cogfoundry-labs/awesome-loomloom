# Security Policy

This repository contains a curated directory rather than a runtime service. Do not disclose credentials, private URLs, personally identifiable information, or exploit details in issues or pull requests.

If an entry exposes a security risk, contains malicious content, or misrepresents its relationship to LoomLoom, report it privately to the repository maintainers through GitHub. Include the project URL, a concise description, and safe reproduction evidence. Maintainers will review the report and remove or annotate the listing when appropriate.
