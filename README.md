# Awesome LoomLoom

> A curated list of community-built projects, integrations, templates, and learning resources for [LoomLoom](https://github.com/cogfoundry-labs/loomloom).

Awesome LoomLoom is a community directory. It helps people discover work built **with** LoomLoom; it is not the LoomLoom source repository, an official support channel, or an application marketplace.

## Entry format

Use this format for every community project:

```md
- [Project name](https://example.com) — What it does in one sentence. `Community` · Compatibility: `vX.Y+` · License: `MIT` · Status: `Active`
```

Use `Official`, `Community`, or `Experimental` as the provenance label. Do not imply official endorsement unless the project is maintained by the LoomLoom team.
